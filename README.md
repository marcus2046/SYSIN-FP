
# SYSIN-FP — PokeAPI Dashboard

A multi-container web application that connects to PokeAPI and displays Pokémon data in a tabbed dashboard.

## 📋 Project Overview
This project is built with a full-stack architecture using Docker containers. It pulls data from the public PokeAPI and presents it through a user-friendly web interface.

## 📁 Folder Structure

- *PokeAPI/* — PokeAPI integration files
- *api/* — Backend API routes and logic
- *db/* — Database configuration
- *frontend/* — User interface and dashboard
- *infra/jenkins/* — Jenkins CI/CD pipeline setup
- *proxy/* — Proxy server configuration
- *.env.example* — Environment variables template
- *.gitignore* — Files Git should ignore
- *docker-compose.yml* — Docker services configuration

## 🛠️ Tech Stack
- *Frontend:* Web UI
- *Backend:* Node.js / Express
- *Database:* Containerized database service
- *DevOps:* Jenkins + Docker Compose
- *External API:* PokeAPI
